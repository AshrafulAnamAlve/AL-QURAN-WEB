# Al-Quran Desktop Application

Cross-platform desktop application for **Al-Quran** built with **Electron + TypeScript + Angular**.

## 🚀 Features

- **System Tray Integration:** Live upcoming prayer countdown in taskbar / system tray.
- **Desktop Adhan & Notifications:** Native background prayer alerts with audio even when minimized.
- **Global Media Keys:** Play, Pause, Skip recitation using physical keyboard media buttons from anywhere in the OS.
- **Offline Ready:** Zero-latency local execution.
- **Cross-Platform:** Windows installer (.exe) & portable, macOS (.dmg), Linux (.AppImage).

## 🛠️ Getting Started

```bash
# 1. Navigate to desktop directory
cd desktop

# 2. Install dependencies
npm install

# 3. Run in development mode (with live frontend)
npm run start:dev

# 4. Package Windows Installer & Portable
npm run package:win
```
